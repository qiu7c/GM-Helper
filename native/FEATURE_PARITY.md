# GM-Helper 原生端功能验收矩阵

用于 Android / iOS 原生重写对照现有 Flutter 功能。样例位于 `native/fixtures/`，内容为虚构信息；不含真实账号或课程数据。

| 功能 | 验收要点 | 状态 |
|---|---|---|
| 登录与会话 | 自绘登录表单与 HTTP 认证；仅验证码和主动扫码显示网页；两次 CAS 建立教务会话；识别“请先登录系统”并提示重新登录 | 已实现，待真机验收 |
| 原生视觉与配色 | 简洁登录页、图标+文字悬浮底栏、以五大节规划首屏，全部课表可滚动查看，课程名/教室不截断；移除主题和自定义背景；按账号/课程保存颜色，详情手选 8 色 | 已实现，待真机验收 |
| 课表解析 | 解析学期、周次、校区选项；课程教师/教室/教学班、单双周与节次；同一格多门课；忽略 sykb2 占位；读取备注 | 已实现，待真机验收 |
| 空周与异常页 | 有完整 `#kbtable` 且零课应作为有效空周；登录失效与无表维护页分别识别，不能把维护页当空课表 | 已实现，待真机验收 |
| 校历 | 读取当前周、总周数和日期；样例为第10/20周、2026-11-04 | 已实现，待真机验收 |
| 个人信息 | 读取虚构姓名、学号、院系等资料字段 | 已实现，待真机验收 |
| 本地缓存 | 按用户、学期、校区、周次隔离；先显示缓存再刷新；真空周可缓存，结构异常不覆盖；退出登录清缓存 | 已实现，待真机验收 |
| 调课差异 | 只比较相同且已知的周次；课程名+星期+大节定位；比较老师、教室、周次；提醒新增、取消、变更 | 已实现，待真机验收 |
| 本地提醒 | 当前提醒基于应用运行时的课表刷新；关 App 后不会自动发现调课 | 已实现，待真机验收 |
| 平台基线 | iOS 15 已确认 | 已实现，待真机验收 |

服务器自动抓取与 Bark 通知已取消，不纳入原生端验收范围。

云验证：685e629 的 Android 构建/Lint/13项单元测试与 iOS Release构建/22项模拟器测试已通过；见 VALIDATION.md。源码实现和自动化测试不能替代真机验收。
