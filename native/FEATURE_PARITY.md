# GM-Helper 原生端功能验收矩阵

用于 Android / iOS 原生重写对照现有 Flutter 功能。样例位于 `native/fixtures/`，内容为虚构信息；不含真实账号或课程数据。

| 功能 | 验收要点 | 状态 |
|---|---|---|
| 登录与会话 | 账号密码及扫码入口；门户成功后经 appShow 建立教务会话；识别“请先登录系统”并提示重新登录 | 待两端编译/真机验证 |
| 课表解析 | 解析学期、周次、校区选项；课程教师/教室/教学班、单双周与节次；同一格多门课；忽略 sykb2 占位；读取备注 | 待两端编译/真机验证 |
| 空周与异常页 | 有完整 `#kbtable` 且零课应作为有效空周；登录失效与无表维护页分别识别，不能把维护页当空课表 | 待两端编译/真机验证 |
| 校历 | 读取当前周、总周数和日期；样例为第10/20周、2026-11-04 | 待两端编译/真机验证 |
| 个人信息 | 读取虚构姓名、学号、院系等资料字段 | 待两端编译/真机验证 |
| 本地缓存 | 按用户、学期、校区、周次隔离；先显示缓存再刷新；真空周可缓存，结构异常不覆盖；退出登录清缓存 | 待两端编译/真机验证 |
| 调课差异 | 只比较相同且已知的周次；课程名+星期+大节定位；比较老师、教室、周次；提醒新增、取消、变更 | 待两端编译/真机验证 |
| 本地提醒 | 当前提醒基于应用运行时的课表刷新；关 App 后不会自动发现调课 | 待两端编译/真机验证 |
| 平台基线 | iOS 15 已确认 | 待两端编译/真机验证 |

服务器自动抓取与 Bark 通知已取消，不纳入原生端验收范围。
